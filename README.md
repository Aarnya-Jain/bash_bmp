### Usage

```bash
git clone https://github.com/Aarnya-Jain/bash_bmp.git
cd bash_bmp
```

- simple_bmp.sh
```bash
./simple_bmp.sh
```

- gradient.sh

```bash
./gradient.sh -w <width> -h <height> -o <output_file_path.bmp>

```

- ascii_to_bmp.sh

```bash
cat <ascii_text_file.txt> | ./ascii_to_bmp.sh -o <output_file_path.bmp>
```
